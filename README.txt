【怎么用】

  双击「index.html」，用浏览器打开即可玩。
  （推荐 Chrome / Edge。完全离线可用，不需要联网。）


【文件夹里有什么】

  index.html         ← 双击这个开始玩（游戏本体）
  game-data.js       ← 真实行情数据（不要删，也不要单独移动）
  echarts.min.js     ← 图表库（不要删，画K线要用）
  README.txt         ← 本文件

  ⚠️ 三个文件必须放在同一个文件夹里。
     单独把 index.html 拷走会读不到数据 ——
     这时页面顶部会弹一条红字说明原因，而不是白屏。


【这是什么游戏】

  随机抽一只真实的A股，隐藏名称和代码，只给你看K线。
  只从「近一年至少涨停过一次的活跃股」里抽 ——
  冷门无行情的票不进池子，练的就是有股性的票。

  每个交易日你只能做一个决定：

      买   全仓买入（按当日收盘价）
      卖   清仓卖出（按当日收盘价）
      过   什么都不做，看下一天

  无杠杆、无加仓、无做T —— 一次只持一个仓位，全进全出。

  快捷键：B = 买　　S = 卖　　空格 = 过


【止损 / 止盈线（买入后才出现，可以直接拖）】

  止损止盈是持仓纪律，只有买进去之后才存在：

      买入后    图上出现两条横向虚线（绿=止损，红=止盈），
                用鼠标或手指上下拖动就能改价位
      卖出后    两条线随仓位一起消失，侧栏面板重新锁上

  默认「自动执行」是关的：线只提示纪律，不替你下单。
  （早期版本默认开着，会出现「刚一买入、第二天就被卖掉」，
    所以现在改成默认关，想要自动卖的人自己去勾。）

  侧栏小面板是同一件事的另一种设法：那里填的是百分比纪律
  （相对买入价）；拖线则是直接定价位，两边自动同步。
  本局用过的纪律会作为下次买入的默认值保留。

  「自动执行」默认是关的 —— 默认情况这两条线只是纪律参考，
  到价了卖不卖，由你自己点「卖」。

  想让它替你执行，就勾上「自动执行」，触发口径和真实挂单一致：
      跳空开盘穿越价位   按开盘价成交（可能比设定价更差）
      盘中触及           按设定价成交
      同一天两边都碰到   按止损优先（悲观口径，练的就是守纪律）

  可设范围：止损 −1% ~ −50%，止盈 +1% ~ +300%。


【为什么标的匿名】

  一旦你知道这是茅台还是某只妖股，你就会用「对它的一贯印象」
  去判断，而不是用K线本身。隐藏身份才能训练纯粹的价格感知。

  复盘时才会告诉你这是什么票、你买完之后它到底怎么走的。


【K线显示多少根】

  图左下角可切换 40 / 70 / 110 根：

      40 根    单根最宽，看单根阴阳线形态最清楚（推荐）
      70 根    默认档
      110 根   能看更长的均线关系和趋势

  无论打到第几天，单根宽度都恒定 —— 不会越玩越糊。


【怎么算分（重点：不看运气，看决策）】

  这个游戏不看你赚了多少钱 —— 因为赚钱可能只是运气。
  抽到一只全年上涨的票，躺着不动也赚，那不算本事。

  真正的指标是「择时超额」：

      你的操作收益  −  同等暴露下躺着不动的收益  =  择时超额

      超额 > 0    你的买卖点判断真的创造了价值
      超额 ≈ 0    你的操作没比躺着更好，白忙
      超额 < 0    你的操作反而害了你，不如什么都不做

  逐笔还会算三个分：
      买点位置      买在了20日区间的什么位置
      持仓煎熬度    持仓期间扛了多少浮亏
      卖点时机      卖完之后价格是涨是跌（跑对了没有）

  综合择时分 = 买点 40% + 扛亏 30% + 卖点 30%


【建议怎么练】

  1. 先别想着赢。前 10 局只是熟悉节奏，看你自己会不自觉地犯什么错。

  2. 最少打 20 局再看累计战绩。单局全看运气，样本不够毫无意义。
     结算页会显示跨局累计（存在浏览器本地，不会上传）。

  3. 刻意练一个东西：你是不是总在「跌了想抄底」和「涨了想追」？
     看你的「买点分」长期在什么水平。

  4. 想验证自己的实盘手法，就用同样的规则打 30 局 ——
     比如你的尾盘买/隔日+2%/-5%规则，就在这里严格照规则执行，
     看累计择时超额是正是负。这比模拟盘记账干净，因为它把
     「选票运气」和「择时能力」分开了。


【数据说明】

  数据来源：腾讯行情接口（前复权日K）
  68 只A股 · 全部是近一年至少有一次收盘涨停的活跃股
  （券商/AI算力/机器人/固态电池/核聚变/军工/稀土/重组等热门题材）
  时间跨度：2025-09-11 至 2026-09-22，每只 250 根真实日K

  全部为真实历史行情，未做任何模拟或生成。
