# 盘感训练器 (Market Sense Trainer)

一个用**真实 A 股日K数据**训练的网页端交易决策练习工具。

核心主张：盘感不是玄学，是**在不确定信息下做决策、并立刻接受后果反馈**的能力。这个工具把复盘压缩成秒级循环，让你在几十局里积累别人几个月才有的决策样本。

## 玩法

每局随机抽一只**匿名**股票，给你一段历史 K 线，然后逐日推进：

| 操作 | 含义 |
|---|---|
| **买** | 全仓买入（单一持仓，不能加仓、不能分批） |
| **卖** | 清仓卖出 |
| **过** | 什么都不做，看下一天 |

- K 线**逐日推进**，你永远只看得到已经发生的部分 —— 没有未来函数。
- 标的匿名显示为 `SIM-XXXX`，**局中不揭示**，结算后才告诉你真实代码和名称。
  > 为什么匿名？因为一旦知道是哪只票，你就会调用"记忆"而不是"判断" —— 那练的是背题，不是盘感。

顶栏可切换 **显示 40 / 70 / 110 根** K 线。窗口恒定，所以无论推进到第 20 天还是第 200 天，单根 K 线的宽度和形态清晰度**完全一致**。

### 止损 / 止盈线（买入后出现，可拖动）

**止损止盈是持仓纪律，只在持仓时存在。** 一买入，图上立刻出现两条横向虚线：绿色是**止损线**，红色是**止盈线**，
**直接用鼠标或手指上下拖动就能改价位**；一卖出，两条线随仓位一起消失，侧栏面板重新锁上。
侧栏面板是同一件事的另一种设置方式 —— 那里填的是**百分比纪律**（相对买入价），两条线会自动同步换算：

| 想干什么 | 怎么做 |
|---|---|
| 精确按百分比定纪律 | 持仓时在侧栏填止损 / 止盈百分比 |
| 直接按价位定线 | 拖动图上的虚线，松手生效 |
| 到价自动卖出 | 勾选「自动执行」（默认关闭） |

- **默认只画线，不代你下单**：`自动执行` 默认关闭 —— 两条线是纪律参考，到价卖不卖由你自己点「卖」。v1 存档里开着的老设置不会被继承（纪律百分比会保留）。
- **只在持仓时可改**：买入后两条线按买入价 × 纪律百分比出现，改完 → 下一交易日起按新价位检查；卖出后线消失、面板锁定。本局用过的纪律会保留为下次买入的默认值。
- **触发口径与真实挂单一致**：跳空开盘已穿越价位 → 按**开盘价**成交（可能比设定价更差）；盘中触及 → 按**设定价**成交；同一天既碰止损又碰止盈（日线上分不出来）→ **止损优先**（刻意选的悲观口径）。
- **可设范围**：止损 −1% ~ −50%，止盈 +1% ~ +300%；止损线恒在参考价下方、止盈线恒在上方，两条线不会互相打架。

## 评分口径（这一节是重点）

游戏不只看你赚了多少钱，而是拆成两个独立维度：

### 1. 绝对收益
就是字面意思，你的账户净值变化。

### 2. 择时超额 (alpha) —— 用**暴露匹配基准**计算

这是整个评分体系里最容易做错的地方，所以说明白：

```
持仓占比   = 你的总持仓天数 / 总可交易天数
基准收益   = 标的整段区间收益 × 持仓占比
择时超额   = 你的实际收益 − 基准收益
```

**为什么要乘持仓占比？**

如果拿"开局买入躺平"当基准，会出一个致命偏差：随机乱点的策略有 75% 的时间是空仓的，而空仓在一只不涨的票上会**自动跑赢满仓** —— 于是评分系统会系统性地奖励"少动手"这个伪技巧，而不是奖励真正的判断力。

实测对比（1080 个随机样本）：

| 基准口径 | 随机交易的 alpha 均值 | 跑输基准的比例 | 是否有偏 |
|---|---|---|---|
| 开局买入躺平 | **+1.10%** | 41.2% | ❌ 严重偏袒空仓 |
| **暴露匹配（本作采用）** | **−0.05%** | **51.6%** | ✅ 左右对称、无偏 |

自洽性三连检验（全部通过）：

- 全程观望 → alpha 恰好 **0.00%**
- 买入持有 → alpha ≈ 0
- 随机交易 → alpha ≈ 0，正负各半

**结论：在这个评分下，你不承担风险就赚不到 alpha。想拿高分只能靠判断，不能靠装死。**

### 3. 逐笔操作打分 (0-100)

每一笔买入/卖出都会单独打分：

- **买点评分**：看买入后一段窗口内，你的买入价距离区间最低点有多近。
- **卖点评分**：看卖出后一段窗口内，你的卖出价距离区间最高点有多近。
- **扛回撤舒适度**：看买入后你承受过的最大浮亏，扛得住给高分。

## 练习建议

1. **先打满 20 局再看累计数据。** 少于 20 局的胜率和盈亏比没有统计意义 —— 样本太小，噪音盖过信号。
2. **盯住"择时超额"而不是"赚了多少"。** 牛市里躺着都能赚，超额才是你真正的贡献。
3. **故意做两个对照组：** 一组凭感觉认真做，一组规定自己"全程只过"。如果两组的 alpha 都在 0 附近徘徊，说明你的判断还没形成正期望 —— 这时候加大实盘仓位就是纯赌博。
4. **可以用同样规则验证实盘手法。** 比如你习惯"尾盘买入、隔日 +2% 止盈、−5% 止损"，就在这个游戏里严格执行这套规则跑 30 局，看 alpha 是正是负。

跨局成绩自动存在浏览器 localStorage 里，关掉页面也不丢。

## 数据说明

- **68 只真实 A 股**，**全部为近一年至少出现过一次收盘涨停的活跃股**（数据来源：腾讯行情接口，前复权日 K）。
- 涨停判定口径：主板 ±10%，创业板 / 科创板 ±20%，北交所 ±30%，ST ±5%；前复权价格留 0.2% 舍入容差。
- 覆盖券商并购、AI 算力 / 光模块、半导体存储、机器人、固态电池、核聚变、军工、华为链、稀土、信创、创新药、并购重组等热门题材；另保留少量仅 1~2 次涨停的大盘活跃股（隆基绿能、中国中免、紫金矿业、韦尔股份、五粮液）作波动梯度。
- **每只 250 根日 K**（约一年），区间 2025-09-11 → 2026-09-22；剔除长期停牌 / 区间不完整的标的。
- 字段：`[日期, 开盘, 最高, 最低, 收盘, 成交量]`。
- 数据文件：`game-data.js`（约 750 KB）。

### 为什么只收录涨停股

训练盘感要练的是**有股性的票**。冷门低波动的蓝筹一年到头没有一次涨停，K 线磨成一条直线，练不出东西 —— 正常选股也几乎没人会去挑这种票。

配套地，开局抽样采用**涨停日锚定**：随机选一个落在决策期内的涨停日，把局拉长到至少覆盖它。实测 60 局抽样：**97% 的局在决策期内真的遇到一次涨停**（其余局的涨停出现在开局预热历史里，图上同样看得到），抽到 42 只不同标的。

## 技术栈

- 纯静态：HTML + CSS + 原生 JavaScript，**零构建、零依赖链**。
- 图表：ECharts 5.5.1，**本地文件 `echarts.min.js` 引入**（离线可用）；本地缺失时自动依次回退 jsdelivr / unpkg / bootcdn，全部失败则在页面顶部给出提示并让游戏降级运行。
- 布局：CSS Grid 响应式双列（大屏 1680px 上限 / ≤900px 退回单列）。
- 时序处理：滑动窗口渲染，保证 K 线宽度恒定。
