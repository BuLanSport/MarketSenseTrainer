# 盘感训练器 (Market Sense Trainer)

一个用**真实 A 股日K数据**训练的网页端交易决策练习工具。

核心主张：盘感不是玄学，是**在不确定信息下做决策、并立刻接受后果反馈**的能力。这个工具把复盘压缩成秒级循环，让你在几十局里积累别人几个月才有的决策样本。

---

## 快速开始

**双击 `盘感训练器.html` 即可。** 不需要安装任何东西、不需要联网、不需要开服务器。

> ⚠️ `盘感训练器.html` 和 `game-data.js` **必须放在同一个文件夹里**。
> 数据是通过相对路径 `src="game-data.js"` 读取的，挪开任何一个都会白屏。

## 玩法

每局随机抽一只**匿名**股票，给你一段历史 K 线，然后逐日推进：

| 操作 | 含义 |
|---|---|
| **买** | 全仓买入（单一持仓，不能加仓、不能分批） |
| **卖** | 清仓卖出 |
| **过** | 什么都不做，看下一天 |

- K 线**逐日推进**，你永远只看得到已经发生的部分 —— 没有未来函数。
- 标的匿名显示为 `SIM-XXXX`，**局中不揭示**，结算后才告诉你真实代码和名称。
  > 为什么匿名？因为一旦知道是哪只票，你就会调用"记忆"而不是"判断" —— 那练的是背题，不是盘感。

顶栏可切换 **显示 40 / 70 / 110 根** K 线。窗口恒定，所以无论推进到第 20 天还是第 200 天，单根 K 线的宽度和形态清晰度**完全一致**。

## 评分口径（这一节是重点）

游戏不只看你赚了多少钱，而是拆成两个独立维度：

### 1. 绝对收益
就是字面意思，你的账户净值变化。

### 2. 择时超额 (alpha) —— 用**暴露匹配基准**计算

这是整个评分体系里最容易做错的地方，所以说明白：

```
持仓占比   = 你的总持仓天数 / 总可交易天数
基准收益   = 标的整段区间收益 × 持仓占比
择时超额   = 你的实际收益 − 基准收益
```

**为什么要乘持仓占比？**

如果拿"开局买入躺平"当基准，会出一个致命偏差：随机乱点的策略有 75% 的时间是空仓的，而空仓在一只不涨的票上会**自动跑赢满仓** —— 于是评分系统会系统性地奖励"少动手"这个伪技巧，而不是奖励真正的判断力。

实测对比（1080 个随机样本）：

| 基准口径 | 随机交易的 alpha 均值 | 跑输基准的比例 | 是否有偏 |
|---|---|---|---|
| 开局买入躺平 | **+1.10%** | 41.2% | ❌ 严重偏袒空仓 |
| **暴露匹配（本作采用）** | **−0.05%** | **51.6%** | ✅ 左右对称、无偏 |

自洽性三连检验（全部通过）：

- 全程观望 → alpha 恰好 **0.00%**
- 买入持有 → alpha ≈ 0
- 随机交易 → alpha ≈ 0，正负各半

**结论：在这个评分下，你不承担风险就赚不到 alpha。想拿高分只能靠判断，不能靠装死。**

### 3. 逐笔操作打分 (0-100)

每一笔买入/卖出都会单独打分：

- **买点评分**：看买入后一段窗口内，你的买入价距离区间最低点有多近。
- **卖点评分**：看卖出后一段窗口内，你的卖出价距离区间最高点有多近。
- **扛回撤舒适度**：看买入后你承受过的最大浮亏，扛得住给高分。

## 练习建议

1. **先打满 20 局再看累计数据。** 少于 20 局的胜率和盈亏比没有统计意义 —— 样本太小，噪音盖过信号。
2. **盯住"择时超额"而不是"赚了多少"。** 牛市里躺着都能赚，超额才是你真正的贡献。
3. **故意做两个对照组：** 一组凭感觉认真做，一组规定自己"全程只过"。如果两组的 alpha 都在 0 附近徘徊，说明你的判断还没形成正期望 —— 这时候加大实盘仓位就是纯赌博。
4. **可以用同样规则验证实盘手法。** 比如你习惯"尾盘买入、隔日 +2% 止盈、−5% 止损"，就在这个游戏里严格执行这套规则跑 30 局，看 alpha 是正是负。

跨局成绩自动存在浏览器 localStorage 里，关掉页面也不丢。

## 数据说明

- **27 只真实 A 股**，覆盖金融 / 消费 / 科技 / 新能源 / 医药 / 周期 / 农业。
- **每只 250 根日 K**（约一年），区间 2025-09-11 → 2026-09-22。
- 字段：`[日期, 开盘, 最高, 最低, 收盘, 成交量]`。
- 数据文件：`game-data.js`（约 320 KB）。

## 技术栈

- 纯静态：HTML + CSS + 原生 JavaScript，**零构建、零依赖链**。
- 图表：ECharts 5（CDN 引入）。
- 布局：CSS Grid 响应式双列（大屏 1680px 上限 / ≤900px 退回单列）。
- 时序处理：滑动窗口渲染，保证 K 线宽度恒定。
